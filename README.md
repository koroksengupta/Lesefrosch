# Lesefrosch
Helping kids read – ein tägliches 8–10-Minuten-Lesetraining für Vorschulkinder (5–6 Jahre, auch DaZ).

**Öffnen:** `index.html` im Browser (Tablet oder Laptop). Eine Datei, keine Installation, keine Netzwerkanfragen, kein Login.

- **Heute** (großer Frosch-Knopf): Tagesmodul = Level 1 Anlaut → Level 2 Silbenschwingen → Level 3 Silben lesen, danach ein Sticker.
- **Elternbereich:** Zahnrad unten rechts **3 Sekunden gedrückt halten** (Ton, Stimme, Tempo, Fortschritt, Freischalten, Ergebnisse, Stimmtest, Lehrplan-Prüfung, Zurücksetzen).
- **Lehrplan bearbeiten:** Array `CURRICULUM` oben im Skript. Die eingebaute Lehrplan-Prüfung (Elternbereich) testet Artikel, Silbentrennung, gelernte Buchstaben, verbotene Anlaute, Abstände verwechselbarer Paare und die 20-%-Wiederholung.
- **Eigene Aufnahmen (optional):** `audio/<id>.mp3` neben `index.html` legen (z. B. `audio/maus.mp3`, `audio/mo.mp3`, `audio/laut-m.mp3` für „mmm"). Die IDs stehen im Stimmtest. Fehlt eine Datei, spricht die deutsche Computerstimme.
